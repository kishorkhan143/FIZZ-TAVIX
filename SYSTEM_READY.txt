COLLECTOR USAGE:

Local machine:
  python collector.py
  (connects to http://127.0.0.1:8000)

Remote machine (Laptop A):
  python collector.py --backend http://100.124.189.109:8000 --label LAPTOP-A
  (sends events to central backend)

Parameters:
  --backend URL      Backend address (default: http://127.0.0.1:8000)
  --label NAME       Machine name (default: hostname)
  --interval SECONDS Poll interval (default: 2)
